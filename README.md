# 🚀 Remnawave Panel Installer

Автоматический установщик Remnawave Panel одной командой.

Automatic one-click installer for Remnawave Panel.

---

## 📋 Возможности / Features

- ✅ Автоматическая установка Docker
- ✅ Выбор Reverse Proxy (Caddy или Nginx)
- ✅ Автоматическая установка SSL сертификата (Let's Encrypt)
- ✅ Генерация всех секретных ключей
- ✅ Интерактивное меню на русском и английском языках
- ✅ Управление панелью (обновление, удаление, логи, бэкапы)

---

##  Быстрая установка / Quick Install

### Одна команда / One command:
bash <(curl -Ls https://raw.githubusercontent.com/blogerandrey-ux/remna/main/install.sh)
